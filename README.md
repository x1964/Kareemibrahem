# Kareem Ibrahem — Portfolio

Personal portfolio of **Kareem Ibrahem**, a full-stack developer building modern web products and AI-powered digital experiences.

🌐 **Live:** [kareem-iota.vercel.app](https://kareem-iota.vercel.app/)

## Features

- **Fully bilingual** — Arabic-first RTL and English LTR, with a persisted language toggle across every page
- **Animated experience** — Lenis smooth scrolling, GSAP scroll-triggered reveals, marquee, magnetic buttons, and staggered section animations (all `prefers-reduced-motion` safe)
- **Project case studies** — detailed `/projects/[slug]` pages in both languages
- **Project intake** — a guided 5-step questionnaire at `/start` for freelance/project inquiries
- **Contact forms** — client-side submission via Web3Forms with `mailto:` fallback
- **SEO ready** — sitemap, robots.txt, Open Graph metadata, canonical URLs

## Tech Stack

- **Framework:** Next.js 16 (App Router, Turbopack) + React 19
- **Language:** TypeScript
- **Styling:** Tailwind CSS 4
- **Animation:** GSAP + ScrollTrigger, Lenis
- **Fonts:** Manrope (English), Thmanyah Serif Display (Arabic)
- **Forms:** Web3Forms

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

### Environment variables

Copy `.env.example` to `.env.local`:

| Variable | Purpose |
| --- | --- |
| `NEXT_PUBLIC_WEB3FORMS_ACCESS_KEY` | Web3Forms key for contact/intake forms (get one free at [web3forms.com](https://web3forms.com)) |
| `NEXT_PUBLIC_SITE_URL` | Production domain for canonical URLs, sitemap, and Open Graph |

Without the Web3Forms key, forms fall back to opening the visitor's email client.

## Scripts

```bash
npm run dev    # Start dev server
npm run build  # Production build
npm run lint   # ESLint
npm run start  # Serve production build
```

## Project Structure

```
src/
  app/            # Routes: home, /projects/[slug], /start, SEO files
  components/
    sections/     # Page sections (Hero, About, Work, Contact, ...)
    ui/           # Shared primitives (Button, Reveal, Marquee, ...)
    layout/       # Navbar, Footer
  data/           # Site content + project data (EN/AR)
  lib/            # i18n, GSAP setup, scroll helpers
public/
  images/         # Portrait, icons, project visuals
  resume.pdf      # Generated by scripts/make-resume.mjs
```
